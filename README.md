# MENUVERSE

Interactive restaurant menus: customers scan a QR code, browse dishes full-screen, turn them in 360° and place them on their table in AR. No app install.

- `index.html`: cinematic swipe menu (Swiss Butter pilot preview)
- `classic.html?r=swiss-butter`: classic list layout
- `classic.html`: sample demo restaurant
- `data/restaurants/*.json`: one menu document per restaurant
- `tools/capture/`: turn a phone video of a dish into a 360° spin
- `PLAN.md`: implementation plan

Swiss Butter content is a pilot preview built from the restaurant's menu board and photos, not yet approved for customers.
